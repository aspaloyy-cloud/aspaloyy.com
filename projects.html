Active Development Go / Raft

Distributed Raft Broker

Высокопроизводительный распределенный брокер логов с собственной реализацией протокола консенсуса Raft. Спроектирован для стабильной репликации данных между нодами, минимальных задержек при обработке сообщений и автоматического восстановления при потере сетевого соединения.

• Детерминированный выбор лидера и репликация состояния
• Бинарный протокол поверх gRPC и Protobuf
• Эффективный append-only лог на диске
Go • Protobuf • gRPC • Raft GitHub ↗
Research & Core Rust / Tokio

Concurrency Sandbox

Набор утилит и бенчмарков для исследования моделей многопоточности, безопасного управления памятью и конкурентного выполнения задач в асинхронном рантайме Tokio. Проект нацелен на анализ накладных расходов при передаче данных между потоками.

• Инструменты профилирования async-задач
• Тестирование безблокировочных (lock-free) структур данных
• Сравнение производительности с классическими примитивами синхронизации
Rust • Tokio • Concurrency GitHub ↗
